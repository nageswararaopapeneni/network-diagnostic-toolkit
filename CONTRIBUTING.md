# Contributing

Thank you for your interest in contributing to the **Network Diagnostic Toolkit**.

Contributions that improve code quality, documentation, usability, and reliability are welcome.

---

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/<your-github-username>/network-diagnostic-toolkit.git
```

3. Create a new branch.

```bash
git checkout -b feature/my-feature
```

4. Make your changes.

5. Test your changes.

6. Commit using a clear commit message.

Example:

```text
feat(dns): add DNS cache inspection
```

7. Push your branch.

```bash
git push origin feature/my-feature
```

8. Open a Pull Request.

---

## Coding Guidelines

- Follow the existing project structure.
- Write modular Bash scripts.
- Keep functions focused on a single responsibility.
- Run ShellCheck before submitting changes.
- Ensure Bash syntax validation passes.

---

## Commit Message Format

Examples:

```text
feat(http): add health check

fix(ssl): improve certificate parsing

docs: update README

refactor(common): simplify validation
```

---

## Reporting Issues

Please include:

- Operating System
- Bash version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant logs or screenshots
