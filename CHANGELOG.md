## [1.0.0] - 2026-08-05

### Added

- Initial stable release
- Modular Bash CLI architecture
- Network Interface diagnostics
- DNS lookup and reverse lookup
- Ping diagnostics
- Port inspection and scanning
- Routing diagnostics
- HTTP status, headers, timing, and health checks
- SSL certificate inspection
- Firewall status and rule inspection
- Active TCP and UDP connection analysis
- Network diagnostic report generation
- Shared validation and logging libraries
- GitHub Actions workflow
- Project documentation
- Demo recording
- MIT License

### Changed

- Improved command-line help
- Added `--help`, `-h`, `--version`, and `-v` support
- Updated project version to **1.0.0**

### Fixed

- Resolved ShellCheck issues
- Improved module loading
- Improved command validation
