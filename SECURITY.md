# Security Policy

## Supported Versions

The latest stable release receives security updates.

| Version | Supported |
|---------|-----------|
| 1.0.x | ✅ |
| < 1.0 | ❌ |

---

## Reporting a Security Vulnerability

If you discover a security vulnerability in this project, please do **not** open a public GitHub issue.

Instead, report it responsibly by contacting the maintainer.

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

Reports will be reviewed as quickly as possible.

---

## Security Best Practices

When using this toolkit:

- Run commands only on systems you own or are authorized to test.
- Avoid scanning third-party systems without permission.
- Review commands before executing them with elevated privileges.
- Keep your Linux system and networking tools updated.
